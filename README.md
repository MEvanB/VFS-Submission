# VFS-Submission
My programming examples 

[Tree Project]

Overview: 
A showcase of 3 different mini projects.
1. Allows you to enter a value between 3-30 and then will create a pyramid with that many lines.
2. Allows you to enter a value between 3-20 and then will create a colored tree with at least that many lines.
3. Plays a coded animation of a Christmas tree with randomized colors for the ornaments all to a jolly tune.

Tools used:
C#
Visual Studio


[Vent Game]

Overview:
A game where you survive indefinitely against a beast hunting you in the vents, timing how long you survive for. Also includes a coded animated flashlight, a battery system, and a jumpscare when you lose.

Tools used:
C#
Visual Studio
